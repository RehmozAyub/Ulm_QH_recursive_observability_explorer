One model, seven ways to read it

Every view is the same live solution, shown from a different angle.

  1. 01TrajectoriesCapability, regulation, observability and the detected population as they evolve over time.
  2. 02Phase DiagramThe path through capability and observability space, with the regime regions shaded behind it.
  3. 03Lambert BoundaryThe critical-capability contour, and where your current settings sit relative to it.
  4. 04Observability FunctionsThe four shapes observability can take with capability, with the active one highlighted.
  5. 05Regime AnalysisThe step-by-step reasoning that sorts a trajectory into one of seven civilisation regimes.
  6. 06Drake DecompositionThe classical Drake count set beside the smaller number this model actually predicts.
  7. 07Recursive Take-offRecursive self-improvement lifts capability, then regulation alone decides whether it stays controlled or runs away into collapse.
