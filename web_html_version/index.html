About the model — the Recursive Observability Filter (ROF)

The ROF is a system of three coupled ODEs in dimensionless time τ over the state vector y = [I, R, O] — capability, regulation, and observability. In static mode only [I, R] are integrated and O is computed post-hoc from the selected O(I) function.

Detection chain:

The model enforces the observation hierarchy — most civilisations that exist are not detectable, and most that are detectable are not observed.
